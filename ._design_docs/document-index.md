## Mandatory document size rules
- IF document exceeds 300 lines THEN split it into smaller logically consistent part files under a same-name subdirectory; in the original document, keep the top-level heading and introductory sections up to the table of contents, then write the remaining content in part files no larger than 300 lines each.
