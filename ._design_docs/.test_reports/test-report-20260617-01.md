### F-17-EXEC-01: server crashes with STATUS_STACK_BUFFER_OVERRUN when `--cache-prompt-evidence raw` is set without `--log-prompts-dir`

- Severity: blocking (drives FAIL on IT5)
- Evidence: it05/server.err.log full body. Server starts and reaches `0.02.499.662 I srv    load_model: initializing slots, n_slots = 1`. At 0.02.575 the process exits with code -1073740791 (0xC0000409 = STATUS_STACK_BUFFER_OVERRUN). The bounded error `raw prompt evidence requires --log-prompts-dir` from server-context.cpp:1499-1501 does NOT print. The validation block is at server-context.cpp:1479-1503 (after the slot init log at line 1382 and inside the load_model() function at line 1108). The crash occurs in the slot init window before the validation runs.
- Control: IT5-rerun with `--log-prompts-dir <p>` set in addition to `--cache-prompt-evidence raw` starts cleanly (Health: ok at 15s, no crash). The crash is reproducible 1/1 when `--log-prompts-dir` is absent and `raw` is selected; the validation logic exists in source but is bypassed or reached after the crash.
- Root-cause hypothesis: the cache validation block at server-context.cpp:1479+ is reached only after the `slots.emplace_back()` loop and the speculative-decoding init at lines 1414-1432. The crash may be in the speculative-decoding init or the slot.reset() call at line 1467 when `cache_prompt_evidence == "raw"`. The crash is not a `std::runtime_error` exit; it is a STATUS_STACK_BUFFER_OVERRUN, indicating a C/C++ buffer overrun or stack corruption in the slot init path that the `raw` mode triggers.
- Action: Developer to investigate the crash site in server-context.cpp:1382-1479 (or the cache controller constructor invoked from create_cache_controller) when `params_base.cache_prompt_evidence == "raw" && params_base.path_prompts_log_dir.empty()`. The validation should be moved BEFORE the model warmup + slot init, or the cache controller constructor should be made safe for raw mode without log-prompts-dir. Confirmed safe path: raw + log-prompts-dir set; confirmed unsafe path: raw without log-prompts-dir.
